# NeuroTrain

NeuroTrain is a brain training mobile app focused on memory, focus, and cognitive improvement for users 40+. It includes gamified features like XP, levels, streaks, badges, and daily challenges.

**Repository:** [github.com/kewry603/neurotrain](https://github.com/kewry603/neurotrain)

## Stack

- **Web:** React, Vite, Tailwind CSS  
- **Mobile:** [Capacitor](https://capacitorjs.com/) (Android)

## Scripts

```bash
npm install
npm run dev          # local dev server
npm run build        # production build
npx cap sync         # copy web build to native projects
```
